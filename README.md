# Jaithra SCS — GitHub Pages website

Complete static website: index.html, about/index.html, styles.css, site.js, and all assets.

Upload the extracted contents to the repository root, not the ZIP itself. In Settings → Pages choose Deploy from a branch, main, /(root), and Save. Keep .nojekyll in the root. No build or database is needed.

Relative links support both a project URL such as https://USERNAME.github.io/REPOSITORY/ and a root/custom domain. Do not remove the assets or JavaScript: they provide the illustrations, videos, navigation, typing, and motion. The homepage filename is index.html.

Publishing creates a public website; the earlier Sites owner-only access gate is not included. No custom domain is configured in this package. Keep existing DNS until GitHub Pages is verified, then configure any desired custom domain separately.

Source: approved Site version 12. Only deployment paths were changed for GitHub Pages compatibility.
